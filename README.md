# NARARYA STUDIO

Digital Creative Studio, Digital Product Store, Design Service & Custom Request.

## Included foundation
- Next.js + TypeScript + Tailwind CSS
- Responsive public website
- Digital product store and detail pages
- Design service catalog
- Custom request flow
- Portfolio and project showcase
- Cart foundation
- Health API
- Security/environment-variable baseline

## Production roadmap
Authentication, PostgreSQL, payment gateway, protected digital delivery, customer dashboard, quotations, revision tracking, tickets, notifications, finance, RBAC, audit logs, analytics and automated tests.

## Run
npm install
npm run dev
